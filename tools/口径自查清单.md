# 口径自查清单

> 结案前、发报表前、和业务方对齐前，过一遍这 15 问。**一票否决制：任何一问答不上来，数字就不要往上报。**
>
> 配套关卡：全部 12 关的通用工具。打印出来贴在工位上也行。

## 一、指标定义（第 1~5 问）

- [ ] **1. 指标名和公式对得上吗？**
  把 SQL 的分子、分母各翻译成一句人话，和指标名逐字核对。"人均活跃天数"的分子必须是**天数**（人日组合数），不是次数；"付费率"的分子必须是**人数**，不是订单数。
  → 相关案件：第 2 关（天数 vs 次数）、第 8 关（人数 vs 订单数）

- [ ] **2. 分子和分母是同一批对象吗？**
  分子剔了退款、分母剔了吗？分子算 paid、分母算全部吗？**分子分母同一 WHERE 条件**，是客单价、留存率、付费率共同的铁律。
  → 相关案件：第 5 关（报表 A 的病）

- [ ] **3. 去重键是什么？**
  user_id、device_id，还是 `COALESCE(user_id, device_id)`？同一用户多设备、多账号怎么算？**先选键，再计数。**
  → 相关案件：第 1 关、第 7 关

- [ ] **4. 游客 / 未登录用户算不算？**
  `COUNT(DISTINCT user_id)` 会**静默忽略 NULL**。游客占比高的产品（内容、工具），漏游客 = 天天少算一截。
  → 相关案件：第 1 关、第 3 关、第 7 关

- [ ] **5. 边界行为归哪一天 / 哪个窗口？**
  23:50 的行为和 00:10 的行为归两天还是一天？次日窗口是"自然日"还是"滚动 24 小时"？归天规则写进文档了吗？
  → 相关案件：第 2 关（跨天归属）、第 3 关（窗口没关）

## 二、数据质量（第 6~10 问）

- [ ] **6. 有没有重复数据？**
  弱网重试的重复上报、任务双跑的重复分区。抽查：`GROUP BY 键 HAVING COUNT(*) > 1`。
  → 相关案件：第 1 关（重复上报）、隐藏支线（双跑）

- [ ] **7. 有没有空值和缺失？**
  空值是被忽略了还是被错误计入了？上游字段（如 `stay_seconds`）和原始明细对得上吗？
  → 相关案件：第 1 关、第 3 关（交叉验证找回）、第 10 关（字段一致性校验）

- [ ] **8. 有没有机器流量 / 刷量？**
  无上游的下游记录（点击无曝光、注册无点击）、等间隔节拍、单设备多账号——三个指纹扫一遍。
  → 相关案件：第 4 关（双侧清洗）、第 9 关（爬虫指纹）

- [ ] **9. 极值处理了吗？**
  均值类指标（时长、客单价）对极值零防御。剔挂起、设截断、并列中位数，三选几？
  → 相关案件：第 10 关

- [ ] **10. 退款 / 0 元单 / 试购怎么算的？**
  整单退款剔不剔？0 元体验课算不算付费？行业惯例 + 自己的口径文档，两头都要有。
  → 相关案件：第 5 关、第 8 关

## 三、统计口径（第 11~13 问）

- [ ] **11. 统计窗口关严了吗？**
  "次日留存"是不是只算了次日当天？报表生成时间点之后的数据还没进来吧？**窗口未完结时，数字只能当参考。**
  → 相关案件：第 3 关

- [ ] **12. 队列和锚点钉死了吗？**
  复购率的队列是哪个月的首购用户？窗口是 30 天还是 90 天？没有队列和锚点的"率"，先把名字改对。
  → 相关案件：第 6 关（月内多单率 ≠ 复购率）

- [ ] **13. 和谁比？口径一致吗？**
  历史基线是同一口径吗？竞对财报的口径脚注读了吗？新增留存 vs 全量留存、ARPU vs ARPPU 互比，是自欺欺人。
  → 相关案件：第 3 关、第 7 关

## 四、流程纪律（第 14~15 问）

- [ ] **14. 口径变更留痕了吗？**
  这次改了去重键、上次改了截断上限——每次变更记日期、记原因、记影响范围。**口径漂移是趋势线断裂的第一大原因。**

- [ ] **15. 异常数字先怀疑谁？**
  顺序背下来：**先怀疑数据（完整性 → 重复 → 空值 → 刷量），再怀疑口径（分子分母 → 窗口 → 去重键），最后才怀疑业务。** 三层全排除，才轮到"用户真的变了"。
  → 相关案件：全部 12 关

## 附：一句话口径卡（面试速记）

| 指标 | 一句话定义 | 必须钉死的三件事 |
|---|---|---|
| DAU | 当日有效互动的去重用户数 | 活跃定义 / 去重键 / 数据完整性 |
| 人均活跃天数 | 去重"人日"组合数 ÷ 人数 | 行为清单 / 归天规则 / 分母人群 |
| 次日留存率 | 某日新增（或活跃）用户次日再活跃比例 | 分母人群 / 活跃定义 / 窗口与完备性 |
| 注册转化率 | 注册用户 ÷ 上游去重人数 | 漏斗节点 / 同键去重 / 双侧清洗 |
| 客单价 | 有效支付订单实付合计 ÷ 订单数 | 订单有效性 / 实付 vs 原价 / 拆单口径 |
| 复购率 | X 月首购用户 N 天内再购比例 | 队列 / 首购锚点 / 窗口 |
| ARPU | 周期总收入 ÷ 全量活跃用户 | 收入清单 / 游客算不算 / 与 ARPPU 区分 |
| 付费率 | 有效付费去重用户 ÷ 活跃用户 | 0 元单 / 退款 / 分母人群 |
| CTR | 有效点击 ÷ 有效曝光 | 曝光口径 / 防抖去重 / 机器流量 |
| 人均停留时长 | 截断后的有效时长均值 | 挂起剔除 / 截断上限 / 中位数并列 |
