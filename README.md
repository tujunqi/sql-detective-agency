# 🕵️ 指标探案馆 · 数字侦探局

**一款剧情向 SQL 探案闯关学习项目。** 你是新入职的数字侦探，通过侦破 12 起业务数据异常案件，掌握互联网高频业务指标的多种口径、歧义点与 SQL 排查方法。

数字侦探局的祖训：**数字不说谎，说谎的是没对齐的口径。**

---

## 项目亮点

- 🧩 **游戏化闯关**：网格探索 + 四连取证解谜 + 限时评级 + 徽章晋升，像玩游戏一样把口径学完；
- 🎮 **双轨玩法**：自带单文件游戏客户端（手机可玩、进度本地保存），也可在 DataGrip 里跑真 SQL 深度办案；
- 📖 **指标口径词典**：一个指标 3~4 种行业口径，逐条拆计算逻辑、适用场景与歧义坑点，覆盖电商 / 在线教育 / 内容平台差异；
- 🧪 **真实脏数据实战**：空值、重复上报、埋点丢失、刷量、拆单、退款、双跑、挂起——每种坑都预埋在可复现的数据里，全部 SQL 在 MySQL 8.0 实测通过；
- 🎯 **面试直给**：每关配"面试标准回答话术 + 两种新手错误写法对比（含偏差数字）"，错误写法都在真实数据上跑过，偏差是多少就是多少。

## 适合人群

- 刷过 SQL 题库，但一进业务就懵的**数据分析求职者**；
- 刚入行、天天被"你们这个数口径对不对"折磨的**数据 / 运营 / 产品新人**；
- 想给团队做**指标口径培训**却缺案例素材的数据负责人。

前置要求：会基础 SQL（SELECT / WHERE / GROUP BY）。不会也行，第 0 关从零教。

## 快速开始

**方式一：直接玩（30 秒）**

浏览器打开 [play/index.html](play/index.html)（或仓库启用 GitHub Pages 后访问对应地址），点「进入侦探局」。走格子探索大厅，踩进 12 间案件室，每间房完成 4 个取证小解谜（🧾 异常数据扫描 → 🗂️ 口径配对 → 🖥️ SQL 拼图 → 🔐 数字保险柜），集齐证据开锁出门、指认根因、领取徽章。手机可玩（方向键 + 点格子自动寻路），进度保存在本地。玩法机制换皮自多款 GitHub 开源游戏：Vim Adventures 式走格子、OverTheWire 式开锁推进、Flexbox Froggy 式即时反馈解谜、SQL Murder Mystery 式证据结案。

**方式二：DataGrip 深度办案（推荐）**

1. 按 [docs/新手入门.md](docs/新手入门.md) 装好 MySQL 8.0 + DataGrip；
2. 打开 [cases/第0关-新人报到.md](cases/第0关-新人报到.md)，复制「案发现场」整段 SQL 运行；
3. 按「探案任务」三步走，自己写 SQL，再对照「真相大白」逐行拆解。

> 每关脚本自带 `DROP DATABASE IF EXISTS`，重复运行即重置，随时重办。

## 每关的结构

每个案件固定六个模块，按同一节奏办案：

1. **前情提要** —— 上关回顾与本案委托；
2. **【案情通报】** —— 业务背景、异常现象、报案人、任务目标；
3. **【指标卷宗】** —— 本关指标的 3~4 种行业口径 + 面试话术 + 新手错误；
4. **【案发现场】** —— 表结构说明 + 可直接运行的建表与脏数据 SQL；
5. **【探案任务】** —— 口径对齐 → 基础核算（限时解码）→ 真相追踪；
6. **【真相大白】与【侦探办案笔记】** —— 逐行注释的参考 SQL、两种错误写法对比（含偏差数字）、口径总结与提问话术。

## 技术说明

- SQL 严格遵循 **MySQL 8.0**（用到 CTE、窗口函数、递归 CTE），全部建表 / 插入 / 答案 / 错误写法 SQL 均在 MySQL 8.0.46 实测通过，可直接在 DataGrip 复现；
- 每关独立建库（`case01_dau`、`case02_active_days`……），脚本重复运行自动重置；
- 案例数据为脱敏小样本（40~80 行），量级缩小、规律与真实业务一致，方便心算复核；
- 游戏客户端为纯前端单文件，零依赖零请求，进度保存在浏览器 localStorage。

## 贡献

发现 SQL 在你的环境跑不通？开 issue 附上 MySQL 版本与报错信息。新案件投稿按每关六模块格式撰写，并保证：所有 SQL 可直接运行、数字与数据真实对得上、至少两种坑点、两种错误写法带偏差数字。
