## 三、SQL 武器库（按案件索引）

| 武器 | 用途 | 首次出场的案子 |
|---|---|---|
| `COUNT(DISTINCT ...)` | 人数口径基石；跨天去重 | 第 0 关 |
| `COALESCE(a, b)` | 空值兜底去重键（注册按账号、游客按设备） | 第 1 关 |
| `GROUP BY ... HAVING COUNT(*) > 1` | 重复上报 / 单设备多账号排查 | 第 1、4 关 |
| `DATE()` 归天 + 跨天比较 `DATE(a) <> DATE(b)` | 归天规则、挂起识别 | 第 2、10 关 |
| CTE（`WITH`）+ `UNION` | 多行为源合并（登录 ∪ 浏览） | 第 3 关 |
| `NOT LIKE` / `LEFT JOIN ... IS NULL` | 剔机器流量；链路断裂（孤儿记录） | 第 4、9、隐藏支线 |
| 自连接（`JOIN` 同表） | 拆单组还原、短时连点检测 | 第 5、9 关 |
| 相关子查询 `EXISTS` | 首购后 N 天内是否再购 | 第 6 关 |
| 恒等式验算（ARPU = ARPPU × 付费率） | 多报表互证 | 第 7 关 |
| 条件聚合 `SUM(CASE WHEN ... END)` | 错法复现、分层付费率 | 第 5、8 关 |
| 递归 CTE `WITH RECURSIVE` | 批量造数、日历表 | 第 9 关、tools 模板 |
| `LEAST(x, 上限)` | 极值截断 | 第 10 关 |
| `ROW_NUMBER() OVER (PARTITION BY ... ORDER BY ...)` | 去重取最早、首购识别 | 隐藏支线 |
| `LAG() OVER (ORDER BY ...)` | 环比、双跑尖峰形态 | 隐藏支线 |
| `AVG() OVER ()` + `ROW_NUMBER` | 手工中位数 | 第 10 关 |
| `TIMESTAMPDIFF(SECOND, a, b)` | 字段一致性校验 | 第 10 关 |

## 四、一句话面试卡

背下这十句，口径类面试题基本封顶：

1. DAU 先钉三件事：活跃定义、去重键、数据完整性。
2. "天数"必须按人日去重，`COUNT(*)` 数出来的永远是次数。
3. 留存四要素：分母人群、活跃定义、时间窗口、数据完备性。
4. 转化率分子分母必须同一批对象、同一套清洗。
5. 客单价铁律：分子分母同一批订单。
6. 复购率标准句式："X 月首购用户的 N 天复购率"。
7. ARPU = ARPPU × 付费率，恒等式验算防口径穿帮。
8. 付费率分子是人不是单；0 元单与退款先表态再算数。
9. CTR 分子分母都会撒谎：分子防抖剔爬虫，分母按基线校准。
10. 均值三道防线：剔挂起、设截断、并列中位数。
