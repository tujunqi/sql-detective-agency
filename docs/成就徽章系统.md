# 成就徽章系统

> 每破一案，解锁一枚徽章。徽章不只是纪念——每枚都对应一个你在该案中掌握的**硬技能**，面试时它们就是你的案例库。

## 一、侦探等级体系

| 等级 | 达成条件 | 称号 |
|---|---|---|
| 见习侦探 | 入局（0~1 枚徽章） | 刚领警徽的新人，还在背 `COUNT` 和 `DISTINCT` 的区别 |
| C级侦探 | 2~4 枚 | 能独立办口径案，报表打架找你评理 |
| B级侦探 | 5~7 枚 | 能拆漏斗、能对账，业务方开口先问"口径钉了吗" |
| A级侦探 | 8~10 枚 | 反作弊、极值、对账通吃，数仓见你绕道走 |
| S级 首席侦探 | 11~12 枚全收集 | 口径豁免权持有者，祖训守护人 |

经验值规则：每破一案 +15%，评级加成：金牌侦探（限时内解码）额外 +5%，银牌（超时但结案）不加不减。

## 三、现实彩蛋徽章（不进系统，进人生）

| 徽章 | 解锁条件 |
|---|---|
| 🧼 **一尘不染** | 任意 5 关的 SQL 一次跑通零报错（包括标点） |
| 🗂️ **卷王侦探** | 把 12 关的「侦探办案笔记」整理成自己的面试卡片 |
| 📣 **口径传教士** | 用第 X 关的案例，成功说服一次真实工作中的口径争论 |
| 🌙 **夜巡完成** | 在凌晨 0 点后办完一案件（深夜食记的传统艺能） |
| 🎓 **考官上身** | 用本项目的坑点给同事出 3 道笔试题，并批改出他们的"错误写法" |

解锁后不需要提交证明——徽章系统的最终用户是你自己的职业信誉。

## 四、办案评级

每个案件的探案任务第 2 步是限时解码（建议 5 分钟）。评级规则：

- ⭐⭐⭐ **金牌侦探**：限时内写出正确 SQL，且口径选择题一次答对；
- ⭐⭐ **银牌侦探**：超时完成，或选择题答错 1 次后纠正；
- ⭐ **铜牌侦探**：看提示后完成（提示不丢人，丢人的是假装会了）。

游戏客户端（`play/index.html`）会自动记录评级；Markdown 模式请自觉诚实，侦探的字典里没有"自欺欺人"。
